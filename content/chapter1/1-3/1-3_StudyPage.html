1.3　半導体を安心して使うためには？

半導体は、スマートフォンや家電だけでなく、自動車、医療機器、鉄道、航空機、産業用ロボット、通信設備など、社会を支えるさまざまな機器に使われています。

もし半導体が突然故障すると、機器が動かなくなるだけでなく、自動車や医療機器などでは人の安全に影響する可能性があります。また、半導体は世界各地で原材料の調達、設計、製造、組立、検査、輸送などが行われるため、一つの企業だけで品質を保証することはできません。

重要ポイント
半導体を安心して使うためには、品質管理・試験 → サイバーセキュリティ → 国際規格 → サプライチェーン管理という考え方が重要です。

1.3.1　厳格な品質管理と試験

半導体は非常に微細な構造を持っています。そのため、製造工程にわずかな異常があっただけでも、性能や寿命に影響することがあります。

例えば、次のようなものが不良の原因になります。

  • 微細なごみや異物
  • 配線の断線
  • 配線間の短絡
  • 膜厚のばらつき
  • 不純物濃度のばらつき
  • 製造装置の条件変化

主な試験

① 外観検査

半導体表面やパッケージなどに傷、汚れ、欠け、異物などがないかを検査します。人による目視だけではなく、カメラや画像処理、AIを利用した自動外観検査も行われます。

② 電気特性試験

完成した半導体に電圧や電流を加え、設計された性能を満たしているか確認します。例えば、電圧、電流、抵抗、動作速度、消費電力などを測定します。

③ 温度試験

半導体は使用する環境によって温度が変化します。そこで、高温や低温の環境でも正常に動作するかを確認します。特に自動車では、夏の高温や冬の低温など厳しい環境で使用されるため、広い温度範囲での信頼性が求められます。

④ 信頼性試験

長期間使用しても故障しないかを確認する試験です。高温、高湿度、温度変化、電圧ストレスなど、実際の使用環境より厳しい条件を与えて故障の可能性を評価することがあります。このような試験を加速試験と呼ぶことがあります。

⑤ バーンイン試験

半導体を一定時間、高温などの条件下で動作させ、使用開始直後に発生しやすい初期故障を発見する試験です。製品の用途や信頼性要求に応じて、試験方法や条件が決められます。

重要ポイント
半導体の品質管理では、完成品だけを検査するのではなく、製造途中から工程を監視し、不良を作り込まないことが重要です。

1.3.2　サイバーセキュリティ対策

半導体の安全性を考えるとき、物理的な故障だけでなく、サイバー攻撃についても考える必要があります。

現在では、自動車、工場、家電、IoT機器など、多くの装置がネットワークに接続されています。半導体を利用したシステムが攻撃されると、情報の盗難、機器の不正操作、システム停止、データ改ざんなどが発生する可能性があります。

そのため、半導体や組込みシステムでは、次のような対策が重要です。

  • 暗号化
  • 認証
  • セキュアブート
  • アクセス制御
  • ファームウェア更新
  • 脆弱性対策

セキュアブート

セキュアブート（Secure Boot）は、機器を起動するときに、実行するソフトウェアが正規のものかを確認する仕組みです。不正に書き換えられたプログラムの実行を防ぐために利用されます。

ハードウェアによるセキュリティ

ソフトウェアだけではなく、半導体チップ内部に暗号鍵を安全に保存したり、暗号処理専用回路を搭載したりする方法もあります。

これからの半導体には、「正しく計算できること」＋「安全に計算できること」が求められます。

1.3.3　国際標準規格の遵守

半導体は世界中で設計・製造・販売されています。そのため、企業ごとに異なる方法で品質や安全性を判断するだけでは十分ではありません。そこで重要になるのが国際規格や各地域の法規制です。

（1）ISO 9001：品質マネジメントシステム

ISO 9001は、組織が製品やサービスの品質を継続的に管理・改善するための品質マネジメントシステム（QMS）に関する国際規格です。

計画する → 実行する → 評価する → 改善する

半導体工場では、作業手順の標準化、記録の保存、不良原因の分析、是正処置、継続的改善などにつながります。

（2）IATF 16949：自動車産業向け品質マネジメントシステム

自動車には、エンジン制御、モーター制御、ブレーキ、エアバッグ、カメラ、レーダー、車内ネットワークなど、非常に多くの半導体が使用されています。

IATF 16949は、ISO 9001を基礎とした自動車産業向けの品質マネジメントシステムで、不良の予防やサプライチェーンにおけるばらつき・無駄の削減などを重視します。

（3）IEC 61508：機能安全規格

電子機器では、故障を完全になくすことは困難です。そこで、故障が発生しても危険な状態にならないようにするという考え方が重要になります。これを機能安全（Functional Safety）といいます。

IEC 61508は、電気・電子・プログラマブル電子システムに関する機能安全の基本的な国際規格です。

安全性の水準を表す考え方として、SIL（Safety Integrity Level）が使われます。SIL1からSIL4まであり、要求されるリスク低減の程度に応じて安全機能を設計します。

（4）ISO 26262：自動車安全規格

ISO 26262は、自動車の電気・電子システムにおける機能安全を扱う国際規格です。

例えば、ブレーキ制御、ステアリング制御、モーター制御、エアバッグ、運転支援システムなどでは、電子回路や半導体の故障が安全に関係します。

ISO 26262では、リスクに応じてASIL（Automotive Safety Integrity Level）という安全度水準を用います。

ASIL A → ASIL B → ASIL C → ASIL D

（5）RoHS指令：特定有害物質使用制限指令

半導体や電子機器では、性能や安全性だけでなく環境への影響も考えなければなりません。

RoHS指令は、電気・電子機器に含まれる特定の有害物質の使用を制限するEUの制度です。

半導体産業では、材料だけでなく、はんだ、端子、パッケージ材料などについても有害物質への対応が必要です。

規格・制度主な目的キーワード
ISO 9001品質管理品質マネジメント
IATF 16949自動車産業の品質管理自動車・不良予防
IEC 61508機能安全SIL
ISO 26262自動車の機能安全ASIL
RoHS指令有害物質の使用制限環境・有害物質
注意
RoHSはISOやIECのような国際標準規格ではなく、EUの法令（指令）です。

1.3.4　サプライチェーンの管理と透明性

半導体は、一つの工場だけで完成するとは限りません。例えば、次のような長い工程を経て製品になります。

原材料 → シリコンウェーハ → 回路設計 → 前工程 → 後工程 → 検査 → 輸送 → 電子機器メーカー

このような原材料の調達から製品が利用者に届くまでの一連の流れをサプライチェーン（supply chain）といいます。

（1）原材料の品質管理

半導体製造には、高純度シリコン、フォトレジスト、各種薬液、特殊ガス、金属材料、パッケージ材料など、多くの材料が使用されます。

半導体は非常に微細な構造を作るため、原材料にわずかな不純物が含まれているだけでも製品の性能に影響することがあります。そのため、純度、成分、異物、供給元、製造ロットなどを厳しく管理します。

（2）製造プロセスの監視

半導体工場では、温度、圧力、ガス流量、膜厚、露光条件、寸法などの製造条件を常に監視します。

製造条件が基準から外れた場合には、異常を早期に発見して不良品の大量発生を防ぐ必要があります。このような考え方では、SPC（Statistical Process Control：統計的工程管理）も重要です。

（3）輸送と保管の適切な管理

完成した半導体も、輸送や保管方法が悪ければ品質が低下することがあります。特に注意する必要があるのが、静電気、湿気、高温、衝撃、振動、汚染です。

半導体素子は静電気に弱いものが多いため、ESD（Electrostatic Discharge：静電気放電）対策が重要です。

例えば、帯電防止袋、導電性容器、接地、リストストラップなどが利用されます。

（4）トレーサビリティの確保

トレーサビリティ（traceability）とは、製品が、いつ、どこで、どの材料を使い、どの装置で、どの条件で製造されたのかを後から追跡できるようにすることです。

例えば、半導体に不具合が発生した場合、次のようにさかのぼって原因を調査できます。

製品番号 → 製造ロット → ウェーハ → 製造装置 → 製造条件 → 原材料

原因となった製造ロットが分かれば、影響する製品を特定して対策することができます。

トレーサビリティの目的
不良発生 → 製造履歴を追跡 → 原因を特定 → 影響範囲を確認 → 製品回収・工程改善 → 再発防止

1.3　まとめ

半導体を安心して使用するためには、次の4つを組み合わせる必要があります。

  1. 品質管理・試験：製造工程を管理し、製品の性能と信頼性を確認する。
  2. サイバーセキュリティ：不正アクセスやデータ改ざんなどからシステムを守る。
  3. 規格・法規制への対応：ISO 9001、IATF 16949、IEC 61508、ISO 26262、RoHSなどに対応する。
  4. サプライチェーン管理：原材料から製造、輸送、保管までを管理し、トレーサビリティを確保する。
原材料 → 製造 → 検査 → 輸送 → 使用 → 不具合情報 → 原因追跡 → 改善
